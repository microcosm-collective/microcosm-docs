/bans

Provides an interface to the bans that exist on the current site. This endpoint is restricted to site owners and moderators of the site's root microcosm.

Bans are applied to site members. A ban can be temporary or permanent, and can include both a public-facing reason and a private administrative reason.

URLs and Methods

URL Pattern Method Description
/api/v1/bans OPTIONS The Allow: header lists the methods available.
/api/v1/bans POST Creates a new ban on the current site.
/api/v1/bans GET Returns information about the bans that exist on the current site.
/api/v1/bans/{id:[0-9]+} OPTIONS The Allow: header lists the methods available.
/api/v1/bans/{id:[0-9]+} GET Returns information about the ban specified by the numeric identifier.
/api/v1/bans/{id:[0-9]+} PUT Updates the ban specified by the numeric identifier.
/api/v1/bans/{id:[0-9]+} DELETE Deletes the ban specified by the numeric identifier.

The banId is based on a sequential number (that spans all sites in the microcosm network). You should not make any assumptions in your code that on a given site the identifiers will be contiguous (that the existence of id=17 infers the existence of id=16, id=15, etc on that site).

Collection

OPTIONS

Example request:

curl -i \
  -X OPTIONS \
  https://dev1.microco.sm/api/v1/bans

Example response:

Content-Type: text/plain; charset=utf-8
Content-Length: 0
Connection: keep-alive
Allow: OPTIONS,GET,HEAD,POST

POST

Creates a new ban on the current site. The structure of the JSON to create a ban is:

{
  "userId": 2,
  "expires": "2026-06-27T12:00:00Z",
  "displayReason": "Repeated spam postings",
  "adminReason": "Warned twice already"
}

Where:

Property Type Optional? Description
userId Integer Required The identifier of the site member to ban. The user must already belong to the current site.
expires String Optional The time when the ban ends, in RFC3339 format. If omitted, the ban is permanent. When supplied on create, the time must be in the future.
displayReason String Optional A public-facing reason that can be shown to the banned user.
adminReason String Optional An internal note for site owners and moderators.

Example request:

curl -i \
  -X POST \
  -H "Authorization: Bearer letmein" \
  -H "Content-Type: application/json" \
  -d '{"userId": 2,"expires": "2026-06-27T12:00:00Z","displayReason": "Repeated spam postings","adminReason": "Warned twice already"}' \
  https://dev1.microco.sm/api/v1/bans

Example response:

HTTP/1.1 302 Found
Date: Fri, 27 May 2026 12:00:01 GMT
Content-Type: application/json
Content-Length: 66
Connection: keep-alive
Location: /api/v1/bans/1

{
 "context": "",
 "status": 302,
 "data": null,
 "error": null
}

Your client should follow the Location header to retrieve detailed information about the newly created ban.

PUT

Updates the ban specified by the numeric identifier. The structure of the JSON to perform the update is the same as create, but userId cannot be changed.

Example request:

curl -i \
  -X PUT \
  -H "Authorization: Bearer letmein" \
  -H "Content-Type: application/json" \
  -d '{"userId": 2,"expires": "2026-07-27T12:00:00Z","displayReason": "Repeated spam postings","adminReason": "Extended after second review"}' \
  https://dev1.microco.sm/api/v1/bans/1

Example response:

HTTP/1.1 302 Found
Date: Fri, 27 May 2026 12:00:05 GMT
Content-Type: application/json
Content-Length: 66
Connection: keep-alive
Location: /api/v1/bans/1

{
 "context": "",
 "status": 302,
 "data": null,
 "error": null
}

Your client should follow the Location header to retrieve detailed information about the updated ban.

DELETE

Deletes the ban specified by the numeric identifier. This operation is idempotent, so deleting a ban that no longer exists still returns success.

Example request:

curl -i \
  -X DELETE \
  -H "Authorization: Bearer letmein" \
  https://dev1.microco.sm/api/v1/bans/1

Example response:

HTTP/1.1 200 OK
Date: Fri, 27 May 2026 12:00:06 GMT
Content-Type: application/json
Content-Length: 66
Connection: keep-alive

{
 "context": "",
 "status": 200,
 "data": null,
 "error": null
