/reports

Reports are moderation cases for comments. Each comment can have one case, and each profile can be recorded once as a reporter. Submitting another report for an existing case adds the reporter without changing the case state, including when the case is closed.

Moderator queue and case endpoints are available to site owners and moderators of the site's root microcosm.

Categories

GET /api/v1/reports/types returns the active categories available to reporters.

curl -i https://dev1.microco.sm/api/v1/reports/types
{
 "context": "",
 "status": 200,
 "data": {
  "reportTypes": [
   {"id": 1, "key": "hate_speech", "title": "Hate speech"},
   {"id": 2, "key": "nudity", "title": "Nudity or sexual activity"}
  ]
 },
 "error": null
}

Submit a report

POST /api/v1/reports requires an authenticated profile. The commentId identifies the comment and type is a category key from the types endpoint.

curl -i \
  -X POST \
  -H "Authorization: Bearer letmein" \
  -H "Content-Type: application/json" \
  -d '{"commentId": 123, "type": "harassment"}' \
  https://dev1.microco.sm/api/v1/reports

The response data contains the case ID, current state, comment link, and the submitting reporter. A repeated submission for the same case does not reopen it.

{
 "context": "",
 "status": 200,
 "data": {
  "id": 42,
  "commentId": 123,
  "commentLink": "/api/v1/comments/123",
  "state": "open",
  "createdAt": "2026-10-12T10:00:00Z",
  "updatedAt": "2026-10-12T10:00:00Z",
  "reporters": [
   {
    "profileId": 7,
    "profileName": "Example",
    "type": {"id": 3, "key": "harassment", "title": "Harassment or bullying"},
    "createdAt": "2026-10-12T10:00:00Z"
   }
  ]
 },
 "error": null
}

Moderator queue and case details

GET /api/v1/reports returns a paginated queue. The optional state parameter accepts open, reviewing, or closed; use limit and offset to paginate.

curl -i \
  -H "Authorization: Bearer letmein" \
  "https://dev1.microco.sm/api/v1/reports?state=open&limit=25&offset=0"

curl -i \
  -H "Authorization: Bearer letmein" \
  https://dev1.microco.sm/api/v1/reports/42

The list response contains a paginated reports collection. Each report includes its comment, state, timestamps, and reporters. A single case response also includes stateChanges, in chronological order.

{
 "context": "",
 "status": 200,
 "data": {
  "id": 42,
  "commentId": 123,
  "commentLink": "/api/v1/comments/123",
  "state": "reviewing",
  "createdAt": "2026-10-12T10:00:00Z",
  "updatedAt": "2026-10-12T11:00:00Z",
  "reporters": [],
  "stateChanges": [
   {"id": 1, "changedByProfileId": 7, "toState": "open", "createdAt": "2026-10-12T10:00:00Z"},
   {"id": 2, "changedByProfileId": 9, "fromState": "open", "toState": "reviewing", "createdAt": "2026-10-12T11:00:00Z"}
  ]
 },
 "error": null
}

Change case state

PATCH /api/v1/reports/{report_id} is restricted to site owners and root microcosm moderators. Set state to open, reviewing, or closed. An optional note is recorded in the state change history. A successful update returns an OK response.

curl -i \
  -X PATCH \
  -H "Authorization: Bearer letmein" \
  -H "Content-Type: application/json" \
  -d '{"state": "closed", "note": "Reviewed and actioned"}' \
  https://dev1.microco.sm/api/v1/reports/42
